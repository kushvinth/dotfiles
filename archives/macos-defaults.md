## Nix-Darwin / Dotfiles Specifics

These are configured via your `~/dotfiles` repo (nix-darwin + stow), not `defaults`:

### Window Tiling Managers
- **yabai** – BSP tiling window manager (with borders, gap padding, sketchybar integration)
- **skhd** – Hotkey daemon (vim-like window focus, space switching, resize)
- **AeroSpace** – Alternative TWM (when not using yabai)

### Menubar (Sketchybar)
Custom menubar replacing macOS default: spaces, battery, bluetooth, volume, wifi, calendar, CPU, brew updates, Spotify, front app, network, GitHub, activity, tailscale

### Keyboard (Karabiner-Elements)
- Caps Lock → Hyper Key (Ctrl+Opt+Cmd+Shift)
- Hyper+[key] → app launchers
- Complex modifications

### Mouse (LinearMouse)
- Per-device acceleration, speed, scrolling (Rapoo, USB Gaming Mouse, Apple Internal Trackpad, Dell)
- Config file: `~/.config/linearmouse/linearmouse.json`

### Ghostty Terminal
- `macos-icon = xray`
- `macos-window-buttons = hidden`
- `macos-option-as-alt = true`
- Window decorations off (for yabai)
- Background opacity 0.8

## Finder: Sidebar & View Options (Reference)

### Sidebar Sections
- **Favorites** (Desktop, Documents, Downloads, etc.)
- **Locations** (iCloud Drive, disks, Network)
- **Tags**

### Use Groups (per-window, not global)
```
Finder → View → Use Groups
```
or `⌘J` → Use Groups
Then Sort By: Kind or Name

Groups appear as: Folders, Images, PDF Documents, Movies, Music...

### Keep folders on top
```
Finder → View → Show View Options (⌘J)
```
Enable: "Keep folders on top: In Windows When Sorting By Name"

If using Groups: ☑ Use Groups, ☑ Keep folders on top

### Hide Preview Pane (right panel)
```
Finder → View → Hide Preview
```
Shortcut: `⇧⌘P`

**Not the sidebar** — sidebar is `⌥⌘S` (left panel with Favorites/Locations/Tags).

### Nix-darwin equivalents (for future)
```nix
{
  system.defaults.finder = {
    ShowPathbar = true;
    ShowStatusBar = false;
    FXPreferredViewStyle = "Nlsv"; # List view
    _FXSortFoldersFirst = true;
    FXEnableExtensionChangeWarning = false;
  };

  # Hide preview pane (no nix-darwin option, use activation script)
  system.activationScripts.finder.text = ''
    defaults write com.apple.finder ShowPreviewPane -bool false
    killall Finder || true
  '';
}
```

> **Note:** "Use Groups" is a per-window/per-folder view preference, not a global Finder preference. It cannot be reliably enforced via `defaults` or nix-darwin.
